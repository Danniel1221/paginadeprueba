# Daniel — Rally Lab

Sitio personal estático de prueba para practicar el flujo de diseño, versionado y despliegue con Figma, GitHub y Vercel.

## Stack

- HTML y CSS estáticos (sin framework ni backend).
- GitHub para guardar el código fuente.
- Vercel para hosting y despliegue continuo.
- Figma para la interfaz editable.

## Ejecutar localmente

Abre `index.html` en el navegador o inicia un servidor estático desde esta carpeta.

## Deploy

Conecta este repositorio en Vercel y selecciona la rama `main`. No requiere build command ni output directory; el proyecto se sirve como sitio estático.

Cada push a `main` puede publicar una nueva versión automáticamente cuando la integración Git de Vercel esté conectada.
